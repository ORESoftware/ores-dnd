# Polyglot governance

The three independent behavioral implementations are TypeScript, Rust, and Dart.
Framework/runtime projections (Flutter and the Rust Dioxus/Leptos/Mash/native/WASM
packages) are explicitly owned by those core participants rather than silently
counted as separate semantic authorities.

The registry binds source layout, CI, the required-runtime contract, the conformance
manifest, and the runtime-evidence adapter table. A new language or projection must
be classified before it can be admitted.
